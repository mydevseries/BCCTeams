# Project rules

- The product name is "BCC Teams". Use the BCC logo in assets/brand/ and the BCC brand
  color defined in apps/web/src/theme/brand.ts.
- Never use Microsoft's logos, product icons (the Teams "T" icon), product names,
  screenshots, UI text or source code. Never decompile or inspect Microsoft's apps.
- Write all feature descriptions and UI text in our own words.
- Only add open-source dependencies with MIT, Apache-2.0, BSD or ISC licenses.
  Ask me before adding anything GPL/AGPL or with an unclear license.
- Never add a dependency that is archived, unmaintained, or has had no release in 12 months.
- Work on one feature from FEATURES.md at a time. Do not change unrelated code.
- Always work on a git branch named feature/<feature-id>, never directly on main.
- If something in FEATURES.md is unclear, ask me before building.
